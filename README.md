# 云端构思板

## 本地开发

需要 Node.js 22.13 或更新版本。运行 `npm ci`，按部署说明配置本机环境变量，然后运行 `npm run dev`。Windows 可使用 `npm.cmd`。

Vite 开发服务只提供页面；AI 接口需要 Netlify Functions 环境。密钥只能通过服务端环境变量配置。

这是部署到 Netlify、使用 Supabase 管理账号、备忘记录和私有截图，并通过服务端 DeepSeek 函数整理原始想法的个人构思板。

核心流转为 **构思 → 待完成 → 进行中 → 已完成**。已完成区只保留今天完成的最近 3 条，其余内容进入可搜索、可恢复的档案。AI 梳理只发送当前卡片的原始文字，并在用户采用后写回整理稿。桌面端支持多张截图的粘贴、拖入、上传、排序、查看和下载；手机端使用紧凑单列，只编辑文字和查看截图。

请按 [部署说明.md](./部署说明.md) 完成 Supabase 初始化或旧站迁移，再由 Netlify 执行 `npm run build`。

本地交付前检查：

```bash
npm run lint
npx tsc --noEmit
npm test
```

测试包括模型单元测试、实际 React 组件账号切换回归、本地 PostgreSQL 迁移回归及构建契约检查。测试数据库在内存中创建并关闭，不访问线上 Supabase。

## 当前边界

这是个人构思板源码，不含账号管理后台、“记住登录”勾选和团队管理；账号需由 Supabase 管理员创建。浏览器会持久化登录会话及本机文字草稿，共享设备上应谨慎使用。

公开源码不代表已完成线上验收。自行部署前，请检查 Supabase 权限、环境变量和账号策略，并验证真实登录、附件及 AI 请求。更新迁移无法恢复旧脚本已经覆盖的截图顺序。
